# BUMIVERSA Global Utility Network

**Vision:** Build Once. Serve Globally. Monetize Responsibly.
**Principle:** Reality before Model. Evidence before Narrative. Utility before Ads.

## Architecture
- **Framework:** Next.js (App Router), TypeScript, Tailwind CSS
- **Hosting:** Vercel / Hostinger (bumiversa.dev)
- **Core Philosophy:** 100% Client-side, Privacy-first, No database, No user tracking.
